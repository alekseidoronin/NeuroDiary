# Как сделать так, чтобы AI в Cursor мог выполнять команды на сервере по SSH

## В чём суть
Нужен вход по SSH-ключу: один раз добавить **публичный** ключ с вашего Mac в `authorized_keys` на сервере — дальше подключение без пароля.

## Что сделать один раз

1. На Mac: показать публичный ключ (обычно `~/.ssh/id_ed25519.pub` или `id_rsa.pub`):
   ```bash
   cat ~/.ssh/id_ed25519.pub
   ```

2. Зайти на сервер (пароль один раз):
   ```bash
   ssh user@YOUR_SERVER_IP
   ```

3. На сервере выполнить (подставьте **свою** строку ключа из шага 1 вместо плейсхолдера):
   ```bash
   mkdir -p ~/.ssh && echo 'PASTE_YOUR_PUBLIC_KEY_LINE_HERE' >> ~/.ssh/authorized_keys && chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys && echo Done.
   ```

4. Проверка с Mac:
   ```bash
   ssh user@YOUR_SERVER_IP
   ```
   Должно пускать без пароля.

После этого из Cursor можно запускать:
`ssh user@YOUR_SERVER_IP 'команда'`

**Не храните приватный ключ (`id_ed25519` без `.pub`) в репозитории.**
