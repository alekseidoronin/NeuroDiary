# Инструкции для AI-агента (diary-bot)

## После изменений в коде

Перед завершением ответа по задаче, если менялись файлы проекта:

1. `git add` — только нужные файлы (без логов и временных скриптов).
2. `git commit -m "краткое описание"`.
3. `git push origin` (текущая ветка).

Подробнее: `.cursor/rules/git-commit-push.mdc` (правило с `alwaysApply: true` для Cursor).

Пользователь ожидает, что это делается **автоматически**, без отдельной просьбы.
